# Security policy

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected security or privacy vulnerability.

Report it privately through [PatchTray support](https://patchtray.io/support). Choose a clear subject such as **Security report** and include:

- the affected PatchTray version;
- a concise description of the impact;
- safe reproduction steps; and
- any relevant logs or screenshots with secrets and personal data removed.

Do not include license keys, recovery codes, payment information, credentials, or another person's data. Please allow time to investigate before publicly disclosing an unresolved report.

## Supported versions

Security fixes are delivered through the newest public release. Update to the latest version before reporting a problem that may already have been corrected.
